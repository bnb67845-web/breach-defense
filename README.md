# 尸潮防线

原创竖屏据点防守 + 肉鸽构筑网页游戏。当前使用本地 Phaser 3.90.0，纯静态前端，无服务端、数据库或构建步骤。

## 本地运行

在项目根目录执行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

浏览器打开 http://127.0.0.1:8765/ 。从根目录提供文件，确保看到最新源码。

## 文件结构

- `index.html`：中文页面入口、移动端视口和全屏画布样式。
- `game.js`：全部游戏逻辑、界面、程序绘制素材和音效。
- `phaser.min.js`：Phaser 3.90.0 本地运行库，避免无故改动。
- `deploy.sh`：复制以上三个文件到 public/，再执行 Wrangler 发布。
- `wrangler.jsonc`：Cloudflare Workers 静态资源部署配置。
- `HANDOFF.md`：接手规则与验证清单。

## 游戏结构

逻辑画布为 540 × 960。Boot 场景生成纹理，Menu 场景展示开始界面，Game 场景负责战斗、波次、升级选择、暂停、胜负和无尽模式。常规目标为 30 波，每波基础时长 20 秒；代码包含存活怪物过多时延后下一波的机制。

浏览器 localStorage 的 zd_best 保存最高波次，zd_mute 保存静音偏好。没有跨设备同步。

## 调试入口

- `/?bot&speed=10`：自动选择升级，用于加速观察；仍需要从菜单启动游戏。
- `/?bot&smart&speed=10`：自动选择升级时参考推荐构筑。
- URL 参数 hp1、hp2、hp3、b1、b2、xpw、dmgw 可覆盖难度参数，定义见 game.js 顶部 TUNE。
- 调试对象：window.__game；bot 模式还会暴露 __TUNE、__waves，以及结束时的 __result。

自动玩法只辅助验证，不能替代真实触控和升级选择测试。

## 部署

现有配置目标：https://game.6.cooking 。该地址来自配置，本次交接未访问或验证线上状态。

需要 Node.js/npm，以及对配置所指 Cloudflare 账号、Worker 和域名的部署权限。完成授权后，在根目录执行：

```sh
sh deploy.sh
```

该命令会直接发布，覆盖对应线上 Worker 的内容。先完成本地验证，并得到项目所有者针对发布的授权。不要为了跑预览执行部署脚本。

public/ 是自动生成的部署目录，不是源码入口，不要直接修改。本包不含 Cloudflare 凭据和本机缓存；wrangler.jsonc 的账号 ID 是部署标识，不是访问令牌。不要将令牌或登录信息写入源码。
